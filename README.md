# Филейный счётчик

Помощник для филейного вязания: загружаешь картинку схемы, приложение находит сетку и закрашенные клетки, а во время вязания ты жмёшь «Провязала» — и видишь, какая клетка следующая.

## Что умеет

- **Импорт схемы из картинки.** Автоматически находит сетку и считает клетки. Если не получилось — можно обвести сетку вручную и указать число клеток.
- **Редактор.** Касанием можно поправить любую клетку, поменять закрашенные и пустые местами или нарисовать схему с нуля.
- **Режим вязания.** Номер ряда и направление (ряды туда-обратно, ряд 1 — нижний), текущая клетка крупно, подсказка вида «3 заполненных подряд, потом 2 пустых», лента ближайших клеток.
- **Вся схема.** Провязанное бледнее, текущая клетка отмечена красным; касание клетки — переход к ней.
- **Библиотека схем** с отдельным прогрессом у каждой.
- Экран не гаснет во время вязания. На компьютере: пробел или Enter — «Провязала», Backspace — шаг назад.

## Как запустить

Приложение без установки зависимостей: `index.html`, папки `styles/`, `scripts/` и `assets/`. Шрифты и изображения включены в проект. `index.html` можно открыть в браузере или опубликовать через GitHub Pages (Settings → Pages → Deploy from branch → `main`, папка `/`).

## Вязание без интернета

Один раз открой опубликованное приложение с интернетом и дождись уведомления «Можно вязать без интернета». После этого оно открывается без сети: схемы, редактор, исходные картинки и прогресс доступны на этом же устройстве. Можно закрыть приложение и продолжить позже. Для быстрого запуска добавь его на главный экран телефона через меню браузера; на компьютере можно установить его из адресной строки поддерживающего браузера.

Автономный запуск установленного приложения требует HTTPS (или `localhost` при разработке). При открытии через `file://` локальные файлы также доступны без сети, но установка приложения и кэширование сайта не включаются. Эта папка сама по себе ещё не публикует сайт.

Данные привязаны к адресу приложения и браузеру. При переходе с локального файла на сайт сначала скачай резервную копию, затем восстанови её на новом адресе по инструкции ниже. Очистка данных браузера удаляет и местный прогресс, поэтому резервную копию стоит хранить отдельно.

Перед публикацией изменений обнови список автономных файлов:

```sh
node scripts/build-offline.cjs
node scripts/build-offline.cjs --check
```

Публикуй всю папку, включая `sw.js`, `offline-assets.js` и `manifest.webmanifest`. Новая версия загружается целиком и включается автоматически. Проверка происходит при открытии, возвращении в приложение, восстановлении сети и раз в минуту в видимой вкладке. На главном экране после короткой паузы страница обновляется сама, предварительно сохранив прогресс. Вязание, редактор, открытые диалоги и ввод текста не прерываются: обновление ждёт возвращения в библиотеку. Без интернета доступна последняя полностью загруженная версия. Страница `update.html` сохранена только для восстановления прежних офлайн-копий.

## Где хранятся данные

- В версии на claude.ai схемы и прогресс синхронизируются между устройствами через аккаунт.
- В автономной версии (этот репозиторий, GitHub Pages) всё хранится в `localStorage` браузера, то есть отдельно на каждом устройстве.

Чтобы перенести данные: «Мои схемы» → «⋯» → «Скачать резервную копию». Передай полученный JSON-файл на другое устройство. Там открой приложение → «Мои схемы» → «⋯» → «Восстановить из копии» → «Выбрать файл». Проверь содержимое и нажми «Восстановить». Текущие схемы останутся, работы из файла добавятся с прогрессом; история активности объединится. Все черновики из копии добавятся к существующим, без замены. Формат и безопасный повтор восстановления описаны в `scripts/backup.js`.

## Планы

- Голосовой ввод: «готово», «назад», «следующий ряд».

## Дизайн-система

Единые правила типографики, компонентов, цветов и адаптивности: [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md). Настройки находятся в `styles/tokens.css`, применение ролей — в `styles/system.css`, геометрия и движение — в `styles/components.css`. Поведение меню, диалогов, ошибок полей и состояний загрузки — в `scripts/ui-components.js`. Перед изменением UI выбирать компонент и его состояния по дизайн-системе, а не создавать отдельный стиль для экрана.


## Проверки

Из корня проекта, без установки зависимостей:

```sh
node tests/ui-components.cjs
node tests/workflows.cjs
node tests/backup.cjs
node tests/knitting-pace.cjs
node tests/knitting-keyboard.cjs
node tests/templates.cjs
node tests/import.cjs
node tests/drafts.cjs
node tests/editor-exit.cjs
node tests/offline.cjs
node scripts/build-offline.cjs --check
```

Первая проверка покрывает размещение меню, клавиатуру, возврат фокуса, закрытие диалогов, блокировку прокрутки, валидацию и загрузку. Остальные — несколько независимых черновиков, перенос прежнего формата, отмену удаления и размеров, прогресс, резервные копии, расчёт темпа, горячие клавиши вязания и переход фокуса, повторное добавление шаблона и распознавание сеток разного размера. Ошибки записи и повтор восстановления проверяются отдельно. Для визуальной приёмки пройти сценарии и размеры из дизайн-системы в браузере.

## Стартовые примеры на GitHub Pages

При первом открытии опубликованной версии в пустом браузере добавляются шесть примерных схем, вымышленная активность за последние 28 дней и примеры замеров темпа. Это демонстрационные данные, а не история пользователя. Существующие схемы, черновики и история не заменяются. При открытии через file:// примеры не добавляются.
