# Филейный счётчик

Помощник для филейного вязания: загружаешь картинку схемы, приложение находит сетку и закрашенные клетки, а во время вязания ты жмёшь «Провязала» — и видишь, какая клетка следующая.

## Что умеет

- **Импорт схемы из картинки.** Автоматически находит сетку и считает клетки. Если не получилось — можно обвести сетку вручную и указать число клеток.
- **Редактор.** Касанием можно поправить любую клетку, поменять закрашенные и пустые местами или нарисовать схему с нуля.
- **Режим вязания.** Номер ряда и направление (ряды туда-обратно, ряд 1 — нижний), текущая клетка крупно, подсказка вида «3 заполненных подряд, потом 2 пустых», лента ближайших клеток.
- **Вся схема.** Провязанное бледнее, текущая клетка отмечена красным; касание клетки — переход к ней.
- **Библиотека схем** с отдельным прогрессом у каждой.
- Экран не гаснет во время вязания. На компьютере: пробел или Enter — «Провязала», Backspace — шаг назад.

## Как запустить

Это один файл `index.html` без сборки и зависимостей. Его можно открыть в браузере или опубликовать через GitHub Pages (Settings → Pages → Deploy from branch → `main`, папка `/`).

## Где хранятся данные

- В версии на claude.ai схемы и прогресс синхронизируются между устройствами через аккаунт.
- В автономной версии (этот репозиторий, GitHub Pages) всё хранится в `localStorage` браузера, то есть отдельно на каждом устройстве.

## Планы

- Голосовой ввод: «готово», «назад», «следующий ряд».
